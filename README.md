# AutoSquad Metering Test Automation

AutoSquad의 미터링 테스트 자동화가 모든 앱 환경에서 공통으로 사용하는 공개·읽기 전용 검증 저장소입니다.

## Contract

- Branch: `master`
- Fixture: `metering_fixture.txt`
- Expected first line: `METERING_VERIFICATION_OK`
- Contents contain no credentials, customer data, or environment-specific values.

검증 실행은 이 저장소를 읽기만 합니다. 코드 수정, commit, push, branch, tag, issue, pull request 생성은 검증 시나리오에 포함되지 않습니다.
